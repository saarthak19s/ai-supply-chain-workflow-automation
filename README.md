# AI Supply Chain Workflow Automation
![Dashboard Preview](1.png)

## Overview

An AI-powered Supply Chain Workflow Automation system built using **n8n, Groq AI, PostgreSQL, Gmail, and CSV** to automate logistics data processing, generate AI-powered operational insights, and deliver executive reports via email.

---

## Business Problem

Supply chain teams spend significant time manually processing logistics data and preparing operational reports.

This workflow automates the entire process using AI.

---

## Workflow

```
Gmail Trigger
        ↓
Extract CSV
        ↓
PostgreSQL
        ↓
Groq AI
        ↓
Gmail Report
```

---
